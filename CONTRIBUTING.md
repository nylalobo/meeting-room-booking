# Contributing

## Branches

- `main` - stable code
- `develop` - active development
- `feature/*` - individual features

## Commit Guidelines

Use clear and descriptive commit messages.

Examples:

- `feat: add user authentication`
- `feat: add meeting room management`
- `fix: prevent overlapping room bookings`
- `docs: update setup instructions`

## Pull Requests

Features should be developed on feature branches and merged into `develop` after review.
